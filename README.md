## Random Users UI

# Description
This project is a simple React application that fetches and displays random user data from an API. The application uses the `useState` and `useEffect` hooks to manage state and side effects, respectively. The user data is displayed in a card format using a separate `UserCard` component.

# Features
- Fetches random user data from the API.
- Displays user information in a card format.
- Uses Tailwind CSS for styling.        

# Technologies Used
- React
- Tailwind CSS
- Fetch API

# Installation
1. Clone the repository:
```bash
git clone <repository-url>
```
2. Navigate to the project directory:
```bashcd random-users-ui
```
3. Install dependencies:
```bashnpm install
```
4. Start the development server:
```bashnpm start
```

# Usage
Once the development server is running, open your browser and navigate to `http://localhost:3000` to see the application in action. The application will fetch and display random user data each time it is loaded.
